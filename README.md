# sotto — download

Official binaries for **sotto (حكي)** — talk, and it types.
The source lives in a private repo; this one hosts the installers.

## Setup (2 minutes)
1. **Mac**: the `.dmg` for your chip (Apple Silicon = `aarch64`, Intel = `x64`) · **Windows**: `.msi` · **Linux**: `.AppImage` / `.deb` / `.rpm`
2. macOS: right-click the app → **Open** on first launch (unsigned build). Allow **Microphone**, then the control permission (on macOS 26 it is called *Device Control and Data Access*).
3. Free API key at [console.groq.com](https://console.groq.com) → paste in sotto Settings → **Test**.
4. Hotkey (default Alt+Space) → talk → hotkey again. Text lands at your cursor.
