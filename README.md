# sotto — download

Official binaries for **sotto (حكي)** — talk, and it types.
The source lives in a private repo; this one hosts the installers.

## Setup (2 minutes)
1. **Mac**: the `.dmg` for your chip (Apple Silicon = `aarch64`, Intel = `x64`) · **Windows**: `.msi` · **Linux**: `.AppImage` / `.deb` / `.rpm`
2. macOS: right-click the app → **Open** on first launch (self-signed build). Allow **Microphone**, then the control permission (on macOS 26 it is called *Device Control and Data Access*). Updates install over and keep permissions.
3. Free Gemini key at [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → paste in sotto Settings → **Test**. Optional: a free [Groq](https://console.groq.com) key as automatic fallback.
4. Hotkey (default Alt+Space) → talk → hotkey again. Text lands at your cursor.

**Engines:** Gemini (default — best Arabic) · Groq fallback for limit days · **Live mode** — your words appear in the pill while you speak, fillers removed.

Note: with a free Google key, Google may use your audio to improve its AI.
